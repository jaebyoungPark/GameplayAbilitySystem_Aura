내가 궁금했던것

: const UAuraAttributeSet* AuraAttributeSet = Cast<UAuraAttributeSet>(ASCInterface->GetAbilitySystemComponent()->GetAttributeSet(UAuraAttributeSet::StaticClass()));

여기서 

1. StaticClass() 의 정체는? UClass*

2. 이미 로드가 된 클래스인가? -> ㅇ

3. 로드된 객체라면 어디서? 난 로드한 적이 없는데? -> AuraAttributeSet 를 Include 한 컴파일 시점에 이미 로드됨

4. 그럼 다른데에선 왜 굳이 RequestAsyncLoad 를 하는거지? -> C++ 를 상속받은 블루프린트 타입일 경우 정적 검사(컴파일)에서 해당 타입 확인 불가. 따라서 동적으로 로드해야 함.
UAuraAttributeSet 는 순수 c++ 타입 클래스이므로, StaticClass 로 컴파일 타임에 막바로 사용 가능함.
